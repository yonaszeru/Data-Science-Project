# Data-Science-Project
Data Science Project .  R Programing language . Statistical Analysis 
This is a Data Science project. In this project, R language is used to 
process data and plot graphs and charts. The following are all the 
R packages and functions used to process data :
  ggplot(): R function to plot graphs
  t.test() : R functions to do two sample t test 
  ggsave() : R function to save graphs into .png and .svc file 

Finally, the process data and graphs are used to make powerpoint
poster
